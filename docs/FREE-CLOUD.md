# ☁️ الحفظ السحابي المجاني — دليل كامل (بلا بطاقة وبلا جوجل)

> **الفكرة**: لوحة حفظ سحابية مجانية 100% تعمل بالتوازي مع Google Play Games والنسخة الاحتياطية المحلية.
> تُبنى على **Firebase Spark (الخطة المجانية)** — لا تحتاج بطاقة ائتمان، لا تحتاج حساب Play Console، ولا تكلف أي شيء.
> حتى قبل التفعيل: اللعبة تعمل **محلية 100%** بدون أي مشكلة — هذه الميزة إضافة اختيارية تُفعل بمجرد إدخال مفتاحين.

---

## 🧭 ملخص سريع

| الخطوة | أين | المدة |
|---|---|---|
| 1. إنشاء مشروع Firebase | متصفح الهاتف | دقيقتان |
| 2. تفعيل تسجيل الدخول المجهول | Firebase Console | دقيقة |
| 3. إنشاء قاعدة Realtime DB بقواعد أمان | Firebase Console | دقيقتان |
| 4. نسخ مفتاحين (api + url) | Firebase Console | دقيقة |
| 5. وضعهما في `tools/sync-cfg.json` من متصفح GitHub | github.com | دقيقة |
| 6. إعادة البناء تلقائيًا عند الحفظ | GitHub Actions | ~6 دقائق |

---

## 1️⃣ إنشاء مشروع Firebase

1. افتح **https://console.firebase.google.com** من أي متصفح وسجّل بحساب جوجل (مجاني).
2. اضغط **Create a project / إنشاء مشروع**.
3. الاسم مثلاً: `tipsybird3d` ثم **Continue**.
4. **Google Analytics**: انقله إلى إيقاف (غير مطلوب) ثم **Create project**.
5. ✅ انتظر حتى تظهر رسالة نجاح ثم **Continue**.

> 💰 لا يوجد أي طلب بطاقة ائتمان — خطة **Spark** المجانية تعطي: 100 متزامن، 10GB حمل/شهر، 1GB تخزين — كافية جدًا للعبة.

---

## 2️⃣ تفعيل الدخول المجهول (Anonymous Auth)

1. من القائمة الجانبية اختر **Build → Authentication** ثم **Get started**.
2. من تبويب **Sign-in method**، ابحث عن **Anonymous** في القائمة.
3. فعّله بستيك On ثم **Save**.

> 🔒 هذه الطريقة تنشئ هوية مجهولة لكل جهاز — **بدون بريد، بدون كلمة مرور، بدون أذونات هاتف**. كل ما تفعله اللعبة هو نداء REST نقي عبر `fetch` — لا SDK ولا كود native.

---

## 3️⃣ إنشاء قاعدة Realtime Database + قواعد الأمان

1. من القائمة الجانبية: **Build → Realtime Database** ثم **Create Database**.
2. الموقع (Location): اختر الأقرب (مثلاً `europe-west1`) ثم Next.
3. في نافذة قواعد الأمان اختر **Start in test mode** (سنستبدلها فورًا).
4. استبدل محتوى القواعد **بالضبط** بهذا ثم اضغط **Publish**:

```json
{
  "rules": {
    "saves": {
      "$uid": {
        ".read": "$uid === auth.uid",
        ".write": "$uid === auth.uid"
      }
    }
  }
}
```

> 🔑 هذه القاعدة تعني: كل جهاز (هوية مجهولة) يقرأ ويكتب **فقط في مجلده الخاص** `/saves/<uid>`. لا أحد يستطيع رؤية حفظ لاعب آخر أو تعديله.

---

## 4️⃣ نسخ المفتاحين

### المفتاح الأول — Web API Key:
1. ⚙️ **Project settings** (رمز الترس).
2. تبويب **General** → قسم **Your apps**.
3. تحت **Web API Key** يظهر مثل: `AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX`
   (إن لم يوجد المفتاح: اضغط أيقونة `</>` وأنشئ تطبيق Web — بدون إضافة شيء فعليًا.)

### المفتاح الثاني — Database URL:
1. من **Realtime Database**: الأعلى يظهر رابط مثل:
   `https://tipsybird3d-default-rtdb.europe-west1.firebasedatabase.app`

احفظ **كلتيهما** في الملاحظات مؤقتًا.

---

## 5️⃣ إدخال المفتاحين في المستودع (من متصفح الهاتف)

1. افتح: `https://github.com/worldnewsportal/Tipsy-Bird-3D-Sky-Adventure/blob/vibe/fully-offline-c73d38/tools/sync-cfg.json`
2. اضغط أيقونة ✏️ (القلم) لتعديله.
3. استبدل محتواه (ضع مفاتيحك الحقيقية):

```json
{
  "api": "ضع_هنا_Web_API_Key",
  "url": "https://ضع_هنا_رابط_القاعدة"
}
```

4. اضغط **Commit changes** (على نفس الفرع `vibe/fully-offline-c73d38`).

---

## 6️⃣ إعادة البناء (تلقائي)

بمجرد الحفظ، GitHub Actions يبني APK جديدًا تلقائيًا. سترى في سجل البناء:

```
cloud sync config: INJECTED (api=AIzaSy..., url=https://...)
```

> ❗ ولو لم تضف المفاتيح أو تركتها فارغة: سيطبع
> `cloud sync config: DORMANT (tools/sync-cfg.json empty or absent) - game stays 100% local`
> واللعبة تبقى محلية بالكامل — لا ضرر أبدًا.

---

## 🔎 كيف يعمل داخل اللعبة (تقنيًا)

1. عند تشغيل اللعبة، محرك `FS` يقرأ مفاتيح `SYNC_CFG` المحقونة من `tools/sync-cfg.json`.
2. إن كانت فارغة/تحتوي `__` فمشغّل السحابة مقفول (`FS.st = 'off'`) — الإعدادات تعرض: `محلي 100% ✓ (السحابة: غير مفعّلة)`.
3. غير ذلك: ينشئ حسابًا مجهولًا عبر `identitytoolkit.googleapis.com/v1/accounts:signUp`.
4. يحفظ `uid/tok/rt` في **`localStorage.tipsy3d_fs`** — خارج بيانات اللعبة نفسها؛ أي `wipe` داخل اللعبة لا يمسح الهوية السحابية.
5. كل تعديل لحالة اللعبة: `St.save()` → `FS.push()` — إرسال مؤجل 9 ثوانٍ (debounce) حتى لا يطلق طلبات متكررة.
6. تغليف اللعبة أو الخروج منها: `FS.doPush(true)` — إرسال فوري.
7. عند الإقلاع: `FS.pull()` — مبدأ **الأحدث فوزًا**: توقيت السحابة `ts` يُقارن بالحفظ المحلي `cloud`، وإن كانت السحابة أحدث تُحمَّل وتُعيد اللعبة تحميل نفسها.
8. لو انتهت صلاحية `token` (~ساعة): يُجدد شفافًا عبر `securetoken.googleapis.com/v1/token`.
9. لو جاء `401`: تفرغ الهوية وتُعاد مصادقة مجهولة جديدة ثم يعاد السحب — كل ذلك موجود في الكود.

## 📱 المعلومات في شاشة الإعدادات

| النص | المعنى |
|---|---|
| `محلي 100% ✓ (السحابة: غير مفعّلة)` | لا مفاتيح في sync-cfg.json — حفظ محلي فقط |
| `…` | السحابة مفعّلة وجاري الاتصال/المصادقة |
| `سحابة مجانية ✓` | مفعّلة وتزامن فعليًا |
| `Google Play ✓` (إن ظهرت) | حفظ Google Play Games مسجّل أيضًا إن اخترت تفعيله |

---

## 🆘 حفظ يدوي (دائمًا متاح حتى بلا سحابة)

زر **تصدير** في الإعدادات ينشئ كودًا نصيًا (`TB3D1.…`) ينسخ إلى الحافظة/الشير —
زر **استيراد** يعيده (على هاتف آخر أو بعد حذف اللعبة).
هذا مستقل تمامًا عن السحابة — يعمل **بدون إنترنت إطلاقًا**.

---

## ❓ أسئلة شائعة

**هل تحتاج بطاقة؟** لا نهائيًا. Spark مجاني بلا بطاقة.

**هل تنتهي البيانات؟** لا — تخزين Firebase دائم. الحصة الشهرية (10GB حمل) كافية لآلاف اللاعبين.

**هل تُخترق بيانات لاعب؟** القاعدة `$uid === auth.uid` تمنع كل قراءة/كتابة عدا لجهازه المجهول نفسه.

**لو حذف المستخدم اللعبة وأعادها؟** لا داعي لفعل شيء — نفس هوية الجهاز المحفوظة في localStorage يسحب الحفظ تلقائيًا. وله أيضًا `استيراد` يدوي بكود النسخة الاحتياطية احتياطًا آمنًا.

**هل يكون الرابط/المفتاح ظاهرًا داخل APK؟** المفتاح `Web API Key` ليس سرًا (هو معرّف مشروع Firebase معياري ويظهر في كل تطبيق ويب Firebase). الحماية الحقيقية هي قواعد القاعدة (`$uid === auth.uid`) — نفس نموذج Firebase الرسمي لكل تطبيقه.
