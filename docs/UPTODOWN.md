## ٣) الصور (من هاتفك فقط)

1. شغّل اللعبة على هاتفك.
2. التقط 3–4 صور (زر خفض الصوت + زر الطاقة في أغلب الهواتف):
   - القائمة الرئيسية (الطائر ثلاثي الأبعاد ظاهر)
   - وسط اللعب مع عملات ودرع
   - شاشة المتجر
   - شاشة المهام أو الإعدادات
3. ارفعها في نموذج Uptodown.
4. الأفضل: التقط بأطور «خارق» لتظهر قوة الجرافيكس.

## ٤) تفعيل GitHub Pages (مرة واحدة — دقيقتان)

> تعذّر التفعيل الآلي (بيانات جلسة النشر لا تملك صلاحية إدارية على الإعدادات) — خطوة يدوية واحدة من هاتفك:

1. افتح: https://github.com/worldnewsportal/Tipsy-Bird-3D-Sky-Adventure/settings/pages
2. **Build and deployment** → **Source**: `Deploy from a branch`.
3. **Branch**: اختر `gh-pages` ثم `/ (root)` → Save.
4. بعد دقيقة افتح: https://worldnewsportal.github.io/Tipsy-Bird-3D-Sky-Adventure/

الفرع `gh-pages` جاهز ويحتوي الصفحة (عربي + إنجليزي، بدون أي موارد خارجية، صالحة للمتاجر).

## ٥) خطوات النشر في Uptodown (من الهاتف)

1. افتح https://business.uptodown.com وسجّل كناشر (Publisher) إن لم يكن لديك حساب.
2. **Submit an app** → ارفع آخر APK موقّع من صفحة Releases (حمّله للهاتف أولًا).
3. املأ النموذج بالنصوص أعلاه (نسخ/لصق)، وارفع `icon-512.png` + لقطات الشاشة.
4. ضع روابط الخصوصية/الشروط من أعلى هذا الملف.
5. التصنيف: للجميع (+3). أعلن أن التطبيق يحتوي إعلانات (Unity Ads).
6. أرسل للمراجعة — عادة 1–3 أيام.

## ٦) قبل الإرسال — قائمة تحقق

- [ ] APK من آخر إصدار Releases (build-28 أو أحدث، موقّع release)
- [ ] versionCode أعلى من أي إصدار سابق — CI يجعله متصاعدًا تلقائيًا (`run_number`)
- [ ] سياسة الخصوصية تفتح وتعمل
- [ ] بريد تواصل صالح
- [ ] 3+ لقطات شاشة حقيقية
- [ ] الاسم والوصف لا يذكران "web" أو "HTML" أو أي كلمات تقنية — النصوص أعلاه نصّفها

## ٧) عند كل تحديث مستقبلي

1. حمّل آخر `build-N` من Releases.
2. Uptodown → إدارة التطبيق → إضافة إصدار جديد → ارفع APK.
3. رقم الإصدار متصاعد تلقائيًا فيسمح بالتحديث بلا تعارض.
