# ☁️ الحفظ التلقائي للتقدم عبر Google Play (تطبيقك أصبح جاهزًا)

## ماذا تم بناؤه؟ (كوديًا جاهز 100%)

تم إضافة **نظام حفظ سحابي حقيقي عبر Google Play Games** (Saved Games / Snapshots API — النسخة v2):

- **تسجيل دخول تلقائي**: اللعبة تسجّل حساب Google Play Games دون أي أزرار من اللاعب (GPGS v2 auto sign-in).
- **حفظ تلقائي كامل**: النقاط، العملات، المفاتيح، السكنات، المابات المفتوحة، المهام، كل شيء — يُرفع سحابيًا تلقائيًا عند كل تقدم (بأقصى 8 ثوانٍ هدوء + عند الخروج من الشاشة مباشرة).
- **سحب تلقائي**: عند تثبيت اللعبة على جهاز جديد، تلقائيًا تسجل الدخول وتنزل الحفظ الأحدث وتُستعاد.
- **آمن من التعارض**: «آخر كتابة يفوز» عبر طابع زمني (St.d.cloud) — لا خسارة بيانات بين الأجهزة.
- **انحدار هادئ (graceful)**: إذا لم تُفعّل الخدمة بعد، أو الجهاز بلا حساب Play، أو اللعبة محمّلة من متجر آخر — تظل اللعبة تعمل 100% بلا أي خطأ، والحفظ المحلي + نسخة أندرويد الاحتياطية يكملان عملهما.

## البنية التقنية

| ملف | الوظيفة |
|---|---|
| `native/PlayGamesPlugin.java` | plugin جديد `PlayGames` — init/signIn/save/load عبر Snapshots API |
| `native/inject_native.sh` | يضيف `play-services-games:23.1.0` + meta-data + تسجيل الـ plugin + تحققات إجبارية |
| `src/index.html` (PB engine) | ربط تلقائي: `St.save()` → رفع مؤجل 8 ثوانٍ، سحب عند الفتح، رفع فوري عند إخفاء التطبيق |
| `tools/games-id.txt` | **(أنت ستنشئه)** الـ Games ID من Play Console — تكتبه في ملف وترفع، وكل البناءات بعده سحابية دائمًا |

> حتى تنشئ `tools/games-id.txt`، البناء يضع قيمة صفرية placeholder والـ plugin يتعامل بهدوء — كل شيء يبقى يعمل كـ «غير مُفعّل» بلا أخطاء.

## خطوات التفعيل (متصفح الهاتف فقط — ~15 دقيقة)

### الخطوة 0 — ما تحتاجه
1. **حساب مطوّر Google Play** (25$ مرة واحدة مدى الحياة): `https://play.google.com/console` → تسجيل → دفع.
2. Google Play يشترط رفع اللعبة له (حتى كاختبار داخلي فقط، بدون نشر عام) لأن الخدمة السحابية تُربط بإصدار مرفوع.

### الخطوة 1 — ارفع اللعبة على Play Console (Internal testing فقط)
1. `https://play.google.com/console` → **Create app** → الاسم: **Tipsy Bird 3D Sky Adventure** → تطبيق → مجاني.
2. أكمل العناصر الإلزامية (التصنيف العمري، سياسة الخصوصية). للخصوصية استخدم:
   `https://worldnewsportal.github.io/Tipsy-Bird-3D-Sky-Adventure/privacy.html`
3. **Testing → Internal testing → Create new release** → ارفع ملف `TipsyBird3D.apk` من آخر إصدار:
   `https://github.com/worldnewsportal/Tipsy-Bird-3D-Sky-Adventure/releases/latest/download/TipsyBird3D.apk`

### الخطوة 2 — فعّل Play Games Services واحصل على الـ Games ID
1. من لوحة Play Console → **Play Games Services → Setup → create project**.
2. **Add Android build** → اختر تطبيقك → أدخل بصمة التوقيع SHA-1 التالية (ثابتة على كل إصداراتنا):

```
06:8F:8D:2C:B8:4B:AF:27:37:9D:E1:01:42:E4:BB:AE:76:1D:D1:D7
```

(شهادة `CN=Tipsy Bird 3D` من `tools/release.p12` — نفس التوقيع المستخدم في كل بناءات GitHub Actions، لذا أي APK تحمّله من الإصدارات سيطابق الرابط.)

3. احفظ ثم انسخ **Games ID** (رقم 12 خانة مثل `123456789012`).

### الخطوة 3 — أدخل الـ ID في المستودع (من متصفح GitHub فقط)
1. المستودع → **Add file → Create new file**.
2. الاسم: `tools/games-id.txt`
3. المحتوى: الصق الـ Games ID فقط (بلا أسطر إضافية) → **Commit changes**.
4. CI ينبني تلقائيًا → بعد نجاحه، تحمّل `TipsyBird3D.apk` → الحفظ السحابي **مفعّل** نهائيًا.

### الخطوة 4 — التحقق
- ثبّت آخر APK → العب قليلًا (نقاط/عملات) → أغلق التطبيق ثم أعد فتحه؛ في شاشة المطور (3 ضغطات على الشعار) ستجد:
  `cloud save: synced | last push time: 17xxxxxxxxxx`
- على جهاز آخر / بعد حذف واعادة التثبيت: أول دخول يعاد تسجيل Play Games تلقائيًا وينزل التقدم.

## الأسئلة الشائعة

**هل انقطاع السحابي يفقد التقدم؟** لا — الحفظ المحلي + نسخة أندرويد الاحتياطية يظلان يعملان، وعند عودة الاتصال يرفع السحابي الأخير أو يسحب الأحدث تلقائيًا.
**هل تحتاج إنترنت دائمًا؟** لا — تعمل بلا إنترنت بالكامل؛ السحب/الرفع فقط عند وجود اتصال.
**هل يخالف اشتراطات المتاجر؟** لا — Play Games Services هو آلية Google الرسمية للحفظ السحابي.
