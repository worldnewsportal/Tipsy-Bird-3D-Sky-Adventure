# قائمة جاهزية Google Play

## ✅ جاهز في المستودع

- [x] اللعبة تعمل 100% دون إنترنت (المحرك والخطوط مضمّنة محليًا)
- [x] لا أذونات حساسة: `INTERNET` (قياسي في كاباسيتور) و`VIBRATE` فقط
- [x] لا جمع بيانات، لا تتبع، لا `eval`، لا تحميل كود من بعيد
- [x] نسخ وإيماءات المتصفح معطلة داخل التطبيق (سلوك تطبيق أصيل)
- [x] `versionCode` يتصاعد تلقائيًا مع كل بناء (`github.run_number`)
- [x] توقيع APK عبر secrets أو مفتاح مؤقت
- [x] أيقونات وشاشة بدء بجميع الكثافات
- [x] إعلانات مكافآت اختيارية فقط (تظهر بموافقة اللاعب ولا تحجب اللعب)

## 📋 مطلوب منك عند الرفع على Play Console

1. **سياسة الخصوصية**: رابط صفحة مكتوبة منك (Play لا يقبل بدونها، خاصة مع وجود إعلانات). أنشئ صفحة بسيطة تشرح: اللعبة لا تجمع أي بيانات شخصية، والإعلانات تشغّلها Unity Ads وقد تجمع بيانات الإعلانات.
2. **نموذج أمان البيانات (Data Safety)**:
   - جمع البيانات: لا شيء من قبل اللعبة نفسها
   - إن فعّلت الإعلانات: أعلن "بيانات الإعلانات" مع الشركة (SDK ثالث)
3. **تصنيف المحتوى (IARC)**: أكمل الاستبيان — مناسبة للجميع.
4. **حالة التطبيق**: عادي (خارج البرنامج العائلي أسهل لأول رفع، especially مع الإعلانات).
5. **التوقيع الأساسي لمتجر Play (App Signing)**: Play يوقّع تلقائيًا عند رفع AAB/APK أول مرة.
6. **الاختبار الداخلي**: ارفع أول نسخة على مسار داخلي واختبرها قبل الإنتاج.

## 🔒 ملاحظات أمنية

- لا مفاتيح أو أسرار داخل الكود إطلاقًا؛ التوقيع يأتي من secrets فقط.
- عدّل `KEYSTORE_BASE64` و`KEYSTORE_PASSWORD` في إعدادات المستودع لإبقاء التوقيع ثابتًا بين التحديثات.
- عند تفعيل Unity Ads، ضع Game ID في `strings.xml` داخل مشروع الأندرويد (خارج المستودع) أو في المكان الموثق في `docs/UNITY_ADS.md`.
